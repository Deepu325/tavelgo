# Plan: Foundation & Security - 01-01

Initialize the Next.js project with Supabase, configure the design system (Tailwind 4 + ShadCN), and implement the core authentication and role-based access control (RBAC) layer.

## Context
- **Phase**: 1 (Foundation & Security)
- **Goal**: Establish a secure, role-based foundation for the Cab Booking app.
- **Must-Haves**: Next.js 16, Supabase SSR, Role-based RLS, Login/Signup UI.

## Threat Model
| Threat | Impact | Mitigation |
|--------|--------|------------|
| Unauthorized table access | High | Enable RLS on all tables; enforce role-based policies. |
| Insecure Server Actions | High | Explicit session check (`getUser()`) in every action. |
| Role spoofing in frontend | Medium | Roles are verified server-side in RLS; frontend only uses roles for UI logic. |
| Credentials leak | Critical | Use Supabase Auth for secure password hashing and session management. |
