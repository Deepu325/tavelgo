# Phase 1 Plan: Foundation & Security (MERN)

## Goal
Establish a working MERN skeleton with JWT authentication and role-based routing.

## Threat Model

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Brute-force login | High | `express-rate-limit` on `/api/auth` |
| JWT secret leak | High | Store in `.env`, never commit |
| Privilege escalation | High | `roleMiddleware` on protected routes |
| NoSQL injection | Medium | Whitelist `req.body` fields before DB ops |
| Password exposure | High | `select: false` on password field in schema |
