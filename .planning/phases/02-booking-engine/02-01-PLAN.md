# Plan: Booking Engine - 02-01

Implement the core booking logic, including database schema for vehicles and bookings, server-side fare calculation, and the customer booking form.

## Context
- **Phase**: 2 (Booking Engine)
- **Goal**: Allow customers to estimate fares and create bookings.
- **Must-Haves**: `vehicles` table, `bookings` table, `BookingForm` component, Server-side fare logic.

## Threat Model
| Threat | Impact | Mitigation |
|--------|--------|------------|
| Fare manipulation | High | Recalculate all fares on the server using authoritative database rates. |
| Unauthorized booking view | Medium | RLS on `bookings` table ensuring `user_id = auth.uid()`. |
| API Key Leak | High | Keep Google Maps API key in server-side env vars only. |
