# Research: Standard Features

Standard and expected features for a modern Cab Booking application in 2025/2026.

## Core Feature Set (Expected by Users)

### 1. Booking Engine
- **Dynamic Pricing**: Real-time fare estimation based on distance and vehicle type.
- **Vehicle Selection**: Visual choice between different tiers (Economy, Premium, Large).
- **Scheduled Rides**: (Optional for MVP but standard) Ability to book for later.

### 2. Driver Experience
- **Real-time Requests**: Low-latency notifications for new bookings.
- **Availability Toggle**: Simple switch for drivers to go online/offline.
- **Trip Management**: Start, Complete, and Navigation integration.

### 3. User Account & Security
- **Secure Login**: JWT/OTP based authentication.
- **Ride History**: Detailed logs of past trips with pricing and driver info.
- **Profile Management**: Roles for Customer, Driver, and Admin.

## Market Standard Benchmarks
- **Booking Speed**: Users expect to confirm a ride in under 30 seconds.
- **Pricing Transparency**: Breakdown of base fare vs. distance-based charges.
- **Status Updates**: Clear visual indicators for "Finding Driver", "Driver Arriving", and "In Progress".

## Innovative/Emerging Features
- **Price Negotiations**: (Not for this project, but common in some regions).
- **Eco-friendly options**: Highlighting electric or hybrid vehicles.

## Competitive Analysis Summary
The primary competitors focus on speed and reliability. Our app differentiates by providing a clean, simple interface without the bloat of multi-modal transport (scooters, bikes, etc.) in the MVP.
