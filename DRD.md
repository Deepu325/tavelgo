# Design Requirements Document

🎨 DRD — Design Requirements Document

Most people either ignore design or overdo it. You need consistency, not creativity chaos.

🎨 1. Visual Style

👉 Choose ONE:
- Flat design (recommended)
- Minimal glassmorphism

Avoid mixing styles → looks amateur.

🎨 2. Color Palette

Example:
- Primary: #2563EB (Blue)
- Secondary: #10B981 (Green)
- Background: #F9FAFB
- Text: #111827

👉 Don’t use random colors per page.

🔤 3. Typography
- Headings: Inter / Poppins
- Body: Inter

🎞️ 4. Motion & Interaction
- Button hover → slight scale
- Page transitions → smooth fade
- Loading → spinner

👉 No animations = boring
Too many = annoying

🎯 5. Components
- Buttons
- Cards (cab selection)
- Input fields
- Modal (booking confirm)

Use:
- ShadCN UI
- Icons: Lucide

📏 6. Layout System
- Spacing: 8px grid system
- Border radius: 8px–12px
- Shadows: subtle only

👉 Bad spacing = instantly unprofessional UI.

⚠️ Final Reality Check
Your structure is now strong enough to build from
But if you:
- Jump to coding without this → chaos
- Ignore pricing logic → broken core
- Skip driver flow → fake system
